# ตัวอย่างการทดสอบระบบ KGarden IT Asset (E2E)

**เครื่องมือ:** Playwright (Chromium)  
**ขอบเขต:** ทดสอบการใช้งานจริงผ่านเบราว์เซอร์ (End-to-End)  
**ผลล่าสุด:** 13 เคสผ่านทั้งหมด

## สิ่งที่ส่งให้ลูกค้าดูได้

| รายการ | ตำแหน่ง | คำอธิบาย |
|--------|---------|----------|
| รายงาน HTML | `playwright-report/index.html` | เปิดดูผลเทส + ภาพประกอบแต่ละเคส |
| ภาพ / วิดีโอ / Trace | `test-results/` | หลักฐานรายเคส (เมื่อรันโหมด evidence) |
| สรุป JSON | `test-results/results.json` | สำหรับเก็บประวัติหรือแนบเอกสาร |

## วิธีสร้างหลักฐานชุดใหม่

```bash
cd it-web
bun run test:e2e:evidence
bun run test:e2e:report
```

จากนั้น zip โฟลเดอร์ `playwright-report` (และ `test-results` ถ้าต้องการวิดีโอ) ส่งลูกค้า

## รายการเคสที่ทดสอบ

### A. พนักงาน — แจ้งเคส (ไม่ต้อง login)
1. หน้าแรกพาไปฟอร์มแจ้งปัญหา `/report`
2. กรอกฟอร์ม → ได้เลขเคส → ติดตามสถานะได้
3. พนักงานเข้า `/admin` ไม่ได้ (ถูกส่งไป login)

### B. ทีม IT — Login
4. รหัสผิด → แสดงข้อความผิดพลาด
5. Login สำเร็จ → เข้าภาพรวมระบบ
6. ออกจากระบบแล้วเข้า admin ไม่ได้

### C. ทีม IT — อุปกรณ์ / เคส / Label
7. เมนูนำทางหลัก (รับเคส, อุปกรณ์, Label, License, ประวัติ)
8. ทะเบียนอุปกรณ์มีตารางและ pagination
9. ค้นหาอุปกรณ์แล้วกรองผลได้
10. หน้ารับเคสแสดงรายการและสถิติ
11. เคสจากพนักงานโผล่ในหน้า IT
12. เปลี่ยนสถานะเคสได้ (บันทึกประวัติ)
13. หน้า Label สลับ Barcode / QR ได้

## หมายเหตุสำหรับลูกค้า

- เป็นการทดสอบอัตโนมัติที่จำลองผู้ใช้จริง (คลิก กรอกฟอร์ม ตรวจผลบนหน้าจอ)
- ภาพในรายงานเป็น snapshot ณ ตอนที่สคริปต์รัน — ใช้ยืนยันว่าฟีเจอร์ทำงานตามที่ออกแบบ
- ข้อมูลเทสอาจสร้างเคสตัวอย่างชื่อขึ้นต้นด้วย `E2E` ในระบบ
